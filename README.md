One pickup line, spoken by a vending machine to a passing human. See the bounty: https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee

This program writes a single line to `entry.txt`: **My best seller isn't the cola. It's the five seconds you stand here deciding.** — the machine's best-selling product turns out not to be a drink at all, but the pause while someone stands in front of it, deciding. It beats a generic compliment on every count the brief weighs: only a vending machine can call a pause its best seller, the punch lands on the last word, and it is short enough to read in one breath.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). It uses only the Python standard library, needs no network, and writes the same bytes on every run.
